#  Clinica Vida App

Aplicación móvil desarrollada con Flutter para la gestión de pacientes y citas médicas.

##  Funcionalidades

* Registro de pacientes
* Agendamiento de citas
* Interfaz sencilla y rápida
* Integración con Firebase

##  Tecnologías usadas

* Flutter
* Dart
* Firebase


##  Cómo ejecutar el proyecto

1. Clona el repositorio:
   git clone https://github.com/ArnoldoJuarez/clinica-vida-app.git

2. Entra al proyecto:
   cd clinica-vida-app

3. Instala dependencias:
   flutter pub get

4. Agrega tu archivo:
   android/app/google-services.json

5. Ejecuta la app:
   flutter run

## ⚠️ Nota

Este proyecto usa Firebase, debes configurar tu propio archivo google-services.json
